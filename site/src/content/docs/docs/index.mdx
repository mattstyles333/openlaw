Canon is **always-on law** for AI agents: git markdown, never retrieved.

This is not a memory product. It is not a runtime. It is not SaaS.

1. Law files every existing harness already loads (`AGENTS.md`, `law/`).
2. CI that enforces them. That is the lock.
3. Optional HTTP MCP — a projection of git, not the source of truth.

**Website:** this site. **Repo:** [github.com/mattstyles333/canon](https://github.com/mattstyles333/canon).  
**Example law:** Northwind Coffee (fictional). Replace it.
