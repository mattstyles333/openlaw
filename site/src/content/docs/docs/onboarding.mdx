## Walkthrough (same story)

## 1. Clone or fork

```bash
git clone https://github.com/mattstyles333/canon.git
cd canon
```

Fork if this will hold *your* organisation’s law. Keep the template MIT.

## 2. Replace `law/`

The tree ships **Northwind Coffee** (fictional, teaching). Replace:

- `law/constraints.md`
- `law/brand.md`
- `law/sor.md`
- `law/priorities.md` (rewrite weekly; do not append forever)

Do not invent policy in chat. If it is not in git, it is not policy.

## 3. Inline three hard rules in `AGENTS.md`

`AGENTS.md` is always-injected. **Max 80 lines / 12 KB.** CI fails if it grows.

Keep the pattern; replace the strings with yours, and replace the grep needles in `scripts/check-law.sh` to match:

- MUST never invent company policy
- always-on law is git markdown, never a vector store
- MUST propose decisions; do not edit law/constraints.md without review

`CLAUDE.md`, `GEMINI.md`, and `.cursor/rules/law.mdc` stay one-line pointers.

## 4. Turn on CI (the lock)

```bash
bash scripts/check-law.sh
```

On GitHub: fork → **Actions** tab → enable workflows if GitHub asks. Push or open a PR. Gates: **law-check**, **secret-scan**, **agent-security**, **mcp-test**. That is the lock. Agents rewrite policy if you let them.

Specialists propose `decisions/*.md` with `status: proposed`. Owners listed in `CODEOWNERS` merge decided law.

## 5. Optional MCP (fail closed)

Only if a cloud agent cannot see the working tree.

- Token: `CANON_MCP_TOKEN`. **Never commit it.** Unset token → refuse to listen. Missing bearer → HTTP 401.
- Pin: `ghcr.io/mattstyles333/canon-mcp:0.1.0`

```bash
export CANON_MCP_TOKEN=          # set in the shell / Portainer UI; not in git
docker compose up -d             # Portainer stack file; port 8787
```

Portainer: new stack `canon-mcp`, paste `docker-compose.yml`, set `CANON_MCP_TOKEN` in the stack env UI. Port 8787 only. No postgres service. Public HTTPS for cloud agents — not tailnet, not stdio, not localhost.

## 6. Attach one harness (docs-only)

Pick the tool you already use. Prefer the working tree over MCP.

### Herdr / Grok Build

Pane **cwd = this git repo**. Grok Build auto-loads `AGENTS.md`.

```bash
cd /path/to/canon
# Herdr: start the pane in this directory.
# New work: a new /goal. Do not grok --resume if you want a blank agent.
bash scripts/check-law.sh
```

Optional HTTP MCP if the pane cannot see git:

```bash
grok mcp add --transport http https://law.example.invalid
```

Replace the URL. Configure the client bearer from `CANON_MCP_TOKEN`. Never commit the token. See `examples/herdr.md` and `examples/grok-build.md`.
