Always-on law for AI agents, stored as git markdown, never retrieved.

Recall is useful. It is not law. If a constraint appears only when an embedding is close enough, it is a search result. Search results are not binding.

## Law vs recall

| | Law | Recall |
| --- | --- | --- |
| Question | What may the agent do? | What did we say last Tuesday? |
| Load | Every session | When similar, when asked |
| Change | Reviewable diff, CODEOWNERS, ADR | Re-embed, hope |
| System of record | git | a vendor index |

## Why git

Diffs are reviewable. `git log law/` is the policy timeline. CODEOWNERS is the permission model. Every mainstream harness already loads `AGENTS.md`.

Git is the source of truth. MCP, if attached, is a projection. Herdr is a multiplexer, not a brain.

## Why not memory products

Mem0, Hindsight, Graphiti, Letta, ByteRover extract, store, and retrieve. That is the right shape for tickets and notes. It is the wrong shape for “never invent company policy.”

Use recall *next to* Canon if you want it. Do not replace `law/` with it. Do not index constraints so they can be “retrieved when relevant.”

## Why CI

Agents rewrite policy if you let them. Language-model instructions are not a control. Size caps, hard-rule needles, ADR frontmatter, secret patterns, and fail-closed MCP — that is the lock.
